Crawler comparison

One page, two HTML files.

The demo app is built twice. The first build is a client-rendered SPA. The second is the same app after snappy-prerender writes each route to HTML. Both panes replay captured frames from those builds. The SPA starts with an empty #root; the prerendered page is readable at t=0 and hydrates later.
