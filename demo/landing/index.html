snappy-prerender

the framework-agnostic react-snap alternative

snappy-prerender is the maintained, MIT-licensed react-snap alternative for existing single-page apps built with React, Vue, Svelte, Preact, Angular, Solid, Lit, Ember or vanilla JavaScript. It prerenders your built SPA to static HTML at build time, verifies hydration, and produces output that Google and AI crawlers can read. No rewrite or runtime service is needed.

Features

What snappy-prerender does.

Frameworks

React, Vue, Svelte, Preact, Angular, Solid, Lit, Ember and vanilla JavaScript, including React 16.8 through 19, Vite 6/7/8 and Create React App; any app that builds to a static directory works.

SEO and discovery

Per-route title, description, robots and canonical tags, Open Graph, Twitter cards, JSON-LD, a built-in Head layer that replaces React Helmet, client-side head reconciliation, sitemap and image sitemap output, sitemap lastmod, robots directives and AI-crawler-readable HTML.

Prerendering

Static HTML per route, directory or flat output, 404.html, route includes/excludes, crawl depth and route caps, route priority, route files, sitemap-seeded routes, per-route overrides, ready flag/selector/network settle, retries, traces and screenshots.

Hydration

Per-route hydration verification, framework detection, strict/re-render/skip policies, changed-only verification, verification-context reuse and per-route failure gates.

Rendering

Playwright with installed Chrome or Edge, hash-verified Chrome for Testing fallback, third-party blocking with host allowlists, authenticated storage state, custom viewport/user agent/HTTPS/launch arguments, scroll-to-load and animation freezing.

Incremental builds

Persistent route cache, API and vendor-asset revalidation, trust/maxAge/exclude modes, per-route opt-out, cache locking with stale-lock recovery and cache pruning for HTML, generated scripts and vendored assets.

Locales

Path and single-locale modes, hreflang and x-default, canonical and og:locale, per-locale routes, cookies/localStorage/storage state, and cookie/localStorage SEO-locale seeding.

Output optimisation

Inline or critical CSS, HTML/CSS minification, preconnect hints, font/image/module preload hints, preload manifest, strict/hash CSP, async and external scripts, tag/attribute surgery, build-origin metadata stripping and stale-route pruning.

Assets and state

Vendor localization for CSS, fonts, images and scripts with content hashing, SRI checks, byte/type limits and redirect/private-host rejection; CSS-in-JS and constructable stylesheet capture; form-state capture; Ajax replay through window.snapStore; self-contained asset gate.

Auditing and operations

Broken-link, SEO, sitemap and CSP audit; duplicate-content/title detection; empty-page and failed-request gates; content drift baselines; deterministic time/timezone/random seed; JSON reports; dry runs, destinations, base paths, serveCmd and bounded concurrency.

Interfaces

Vite plugin, CLI, interactive init wizard, react-snap config migration and programmatic API.

Why this matters

Prerender a React SPA without SSR, or any other SPA.

A client-rendered SPA ships an empty root and a JavaScript bundle. snappy-prerender runs after the build, opens every route in a real browser, and writes the settled DOM to static HTML. That is SPA prerendering without a server renderer, a framework migration or a runtime service. The same build works for React, Vue, Svelte, Preact, Angular, Solid, Lit, Ember and vanilla JavaScript.

Every major SPA framework

Use the Vite plugin, the CLI or the init wizard to prerender Vite output, Create React App output or any static directory. The testcase matrix builds React 16.8 through 19, Vue 3.x, Svelte 3/5, Preact 10/11, Angular 10/22, Solid 0.20/1.9, Lit 1/3, Ember 3.22/7.3 and vanilla JavaScript.

What AI crawlers see

GPTBot, ClaudeBot and PerplexityBot fetch HTML without waiting for a browser render. The prerendered page gives them the content, title, description, canonical and Open Graph tags in the first response.

A maintained react-snap replacement

react-snap's last npm release was 2018 and its React 18 compatibility issue has been open since 2023. snappy-prerender keeps the build-time browser approach for React, Vue, Svelte, Preact, Angular, Solid, Lit, Ember and vanilla JavaScript, with Playwright and per-route hydration verification.

SPA SEO without SSR

Prerendered HTML gives Google and AI crawlers a readable page on the first request for React, Vue, Svelte, Preact, Angular, Solid, Lit, Ember and vanilla apps. The client bundle still hydrates normally, so the app keeps its router and interactivity.
